Accesos rápidos
Cómo se conectará
  1. El usuario escribe un ID o dato de búsqueda.
  2. La página envía la consulta a una API.
  3. La API consulta SQL Server.
  4. Se cargan los datos relacionados y se muestran en la ficha.
El HTML no guarda credenciales de SQL Server. La conexión se hará desde el backend.
